# Ping-tool — Gaming Server Monitor v13

## ما الذي تغير؟

هذه النسخة توقف القياسات القديمة من خادم Render. كانت تلك القياسات تقيس مسار Render إلى عناوين خارجية، ولا تمثل اتصال جوال المستخدم أو Ping المباراة. الواجهة الآن تعرض مناطق مرجعية ومصدرها، وتعرض «غير متاح» بدلاً من أرقام مضللة.

## تشغيل محلي

```bash
python ping_monitor.py
```

افتح `http://127.0.0.1:8765`.

## النشر على Render

المشروع يحتفظ بـ `render.yaml` وDockerfile الحاليين. ارفع محتويات الإصدار إلى جذر مستودع `Ping-tool`، ثم انتظر Auto Deploy أو نفّذ Manual Deploy. تحقق من `/health`.

## ما لا تدعيه هذه النسخة

- لا تقيس Ping المباراة.
- لا تقيس ICMP من المتصفح.
- لا تعتبر Tencent Cloud خادم PUBG.
- لا تعرض Ping مستنتجاً من Render على أنه Ping جهاز المستخدم.

## المتطلب الحقيقي للمرحلة التالية

يلزم نشر نقاط اختبار إقليمية فعلية مع WebSocket/WSS، ثم يبدأ المتصفح الاتصال بها مباشرة عبر اتصال الجهاز الحالي. نحتاج نقاطاً في المناطق المطلوبة، مع توثيق موقع كل نقطة. وحتى بعد ذلك يجب تسمية النتيجة RTT إلى نقطة الاختبار، لا Ping المباراة، إلا عند إثبات أن الوجهة هي خادم المباراة نفسه.
