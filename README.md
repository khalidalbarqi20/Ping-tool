# Gaming Server Monitor v14.2

- يقتصر العرض على PUBG Mobile وFortnite — الشرق الأوسط فقط.
- يحتفظ بقياس Cloudflare Edge كقياس عام منفصل.
- يعرض معايير التصنيف التي زود بها المستخدم: PUBG 20–35 ممتاز، 36–99 متوسط، 100+ سيئ؛ Fortnite 60–70 ممتاز، 71–119 متوسط، 120+ سيئ.
- لا يطبق هذه المعايير على Cloudflare RTT؛ لأن وجهة القياس مختلفة عن خادم المباراة.
- PUBG: لا يوجد عنوان موثق لخادم المباراة متاح حالياً للقياس المباشر من المتصفح.
- Fortnite: عنوان Epic في البحرين مرجع اختبار، لكن المتصفح لا يرسل ICMP مباشرة.

## Deployment
نفس خدمة Render الحالية؛ ارفع الملفات إلى GitHub وسيعمل النشر التلقائي. Worker الحالي يبقى كما هو ويقيس Cloudflare Edge فقط.
