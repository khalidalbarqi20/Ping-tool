# Gaming Server Monitor v16.0

- يحافظ على قياس Cloudflare WebSocket العام الموجود سابقًا.
- يضيف اختبار HTTP إقليميًا مباشرًا من المتصفح إلى 16 نقطة AWS DynamoDB في الشرق الأوسط وآسيا/المحيط الهادئ.
- 3 محاولات لكل منطقة، بحد أقصى 6 طلبات متزامنة ومهلة 2500ms.
- يعرض آخر استجابة ناجحة، ووسيط العينات الناجحة، وعدد المحاولات الناجحة والفاشلة.
- لا توجد أي منطقة إسرائيلية في القائمة؛ `il-central-1` مستبعد صراحةً.
- هذه القياسات تقديرات HTTP إلى AWS، وليست بنق خوادم PUBG أو Fortnite أو فقدان UDP.

## نقاط الاختبار

تستخدم الواجهة نمط AWS DynamoDB regional API endpoint: `https://dynamodb.<region>.amazonaws.com/` مع GET و`no-cors` و`cache: no-store` وبيانات اعتماد مستبعدة. يوقف الاختبار عند إخفاء التبويب.

## التشغيل

`python ping_monitor.py` ثم افتح المنفذ المحدد في `PORT` (الافتراضي 8765).
