# Ping-tool — Gaming Server Monitor (v12)

مشروع ويب لمراقبة استجابة وجهات اختبار مرتبطة بالألعاب. هذه النسخة تحافظ على ملفات ومزايا v11، وتضيف إعداد نشر على Render Free وتحسينات تشغيل أساسية.

## تنبيه دقة أساسي

**القياسات في هذه النسخة تنفذ من خادم Python المستضاف، وليس من جهاز الزائر.**
- Fortnite: محاولة ICMP إلى أسماء نطاقات اختبار Epic الموجودة في `games.json`.
- PUBG Mobile: زمن اتصال TCP إلى نقاط Tencent Cloud على المنفذ 443، وهو قياس تقريبي لمركز سحابي وليس خادم المباراة.
- EA FC وCall of Duty: لا توجد عناوين قياس موثقة في بيانات المشروع، لذلك لا تظهر لهما أرقام Ping.
- لا يجوز اعتبار هذه الأرقام Ping المباراة أو Ping شبكة المستخدم.

قياس Ping من واي فاي المستخدم أو بيانات جواله يحتاج أن تكون نقطة القياس في الطرف الآخر وأن ينشأ الاتصال من المتصفح إلى تلك النقطة. المتصفح لا يسمح بـ ICMP التقليدي أو UDP الخام. لذلك هذه النسخة **مرحلة نشر وتجربة للبنية الحالية** وليست تحقيقاً نهائياً لميزة قياس Ping من جهاز المستخدم.

## تشغيل محلي

يتطلب Python 3.9 أو أحدث. لا توجد مكتبات خارجية مطلوبة.

```bash
python ping_monitor.py
```

افتح `http://127.0.0.1:8765`.

## النشر المجاني على Render

1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub الحالي `Ping-tool` (لا ترفع المجلد الأب).
2. في Render اختر **New → Blueprint**، واربط مستودع GitHub.
3. سيقرأ Render ملف `render.yaml` وينشئ Web Service بالخطة Free باستخدام Dockerfile، الذي يضيف أداة `ping` المطلوبة لاختبارات ICMP.
4. بعد اكتمال النشر افتح رابط `onrender.com`، ثم تحقق من `/health`.

بديل: أنشئ Web Service يدوياً:
- Environment: Docker
- Dockerfile Path: `./Dockerfile`
- Plan: Free

لا يلزم إدخال بطاقة دفع بحسب خطة Render Free الحالية، لكن راجع حدود حسابك قبل النشر.

## حدود Render Free

- الخدمة المجانية تدخل السكون بعد 15 دقيقة دون طلبات واردة؛ أول طلب بعد السكون قد ينتظر قرابة دقيقة حتى تستيقظ.
- فتح لوحة الموقع وتحديثها دورياً يبقي الخدمة نشطة أثناء الاستخدام، لكنه لا يضمن مراقبة خلفية 24/7 عندما لا يوجد زوار.
- نظام الملفات مؤقت؛ `snapshots.json` و`custom.json` قد يفقدان محتواهما بعد إعادة تشغيل/نشر/سكون الخدمة.
- Render قد يعيد تشغيل الخدمة، والموارد المجانية مخصصة للتجارب والمشاريع الشخصية وليست ضمان تشغيل إنتاجي دائم.

## ملفات المشروع

- `Dockerfile`: بيئة التشغيل وتثبيت أداة `iputils-ping`.
- `index.html`: واجهة المراقبة.
- `ping_monitor.py`: خادم HTTP ومحرك القياس الحالي.
- `games.json`: الألعاب ومناطق القياس وعناوين الاختبار.
- `SPEC.md`: مواصفات القياس والحسابات.
- `LIMITS.md`: القيود المعروفة.
- `SOURCES.md`: مصادر عناوين الاختبار.
- `render.yaml`: إعداد النشر.
- `requirements.txt`: متطلبات Python.
- `Procfile`: أمر تشغيل متوافق مع منصات PaaS.

## الخطوة الهندسية التالية

بناء قياس من جهة المستخدم إلى نقاط اختبار مستقلة في مناطق متعددة. لا يمكن اعتبار نقطة واحدة في Render بديلاً عن نقاط البحرين/الإمارات/أوروبا، ولا يمكن تسمية RTT إلى Tencent Cloud أو Epic ping بأنه Ping المباراة دون تحقق.
